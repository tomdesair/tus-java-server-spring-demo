Tus Java File Upload Server Demo with Spring Boot

Select a storage backend test page to upload files using the Uppy Dashboard:

  • Disk Storage Backend (Default) — Stores uploads on the local filesystem or mounted network share using DiskStorageService and LeaseFileLockingService.
  • S3 Object Storage Backend — Stores uploads in AWS S3 or MinIO using S3StorageService and S3LockingService.
  • Azure Blob Storage Backend — Stores uploads in Azure Blob Storage using AzureBlobStorageService and AzureBlobLockingService.
